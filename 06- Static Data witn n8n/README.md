# Three.js Space Mission Dashboard

## Features

- Three.js
- Orbit Controls
- Environment Map
- GLB Model Loading
- n8n Webhook Integration
- Live Telemetry Dashboard

## Getting Started

1. Clone the repository
2. Open with VS Code
3. Run Live Server
4. Replace WEBHOOK_URL with your own n8n webhook
5. Click Get Telemetry
